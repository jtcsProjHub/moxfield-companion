Collection Companion

All data stays in this browser profile. Nothing syncs on its own except the optional Scryfall refresh.

1. Scryfall card data and tags

Card text comes from Scryfall's Oracle Cards bulk file (about 25 MB). Function tags come from Scryfall Tagger's Oracle Tags bulk file (about 6 MB). Both update daily on Scryfall.

Import files you downloaded yourself

Use the oracle-cards-*.jsonl.gz and oracle-tags-*.jsonl.gz files from scryfall.com/docs/api/bulk-data.

2. Your collection

Import a file

On Moxfield, open your collection and use Export (CSV). Rows marked as proxy (playtest) are kept as playtest copies. A plain list such as "4 Lightning Bolt" also works.

Or sync a public collection

This needs your Moxfield collection to be public. Leave the box empty to find it from the user name in section 3, or paste its link (moxfield.com/collection/…).

Names not found in the card data

Usually tokens, emblems and other non-deck cards.

3. Your decks

Public decks only. Cards in counted decks are not "free" in other decks. Sync updates only decks that changed on Moxfield.
